## 2. Princípios de Arquitetura e Segurança

1. **Zero Duplicação:** Antes de criar qualquer tabela, verificamos os 12 schemas existentes (`canonical`, `raw`, `core`, `market`, `asset_details`, `analytics`, `wealth`, `social`, `dw`, `system`). Entidades já existentes recebem apenas `ALTER TABLE ... ADD COLUMN IF NOT EXISTS`. Novas tabelas são criadas exclusivamente para relações `1:N` / `M:N` que não existiam no modelo.
2. **Zero Invenção:** Toda coluna, tabela, enum e seed possui rastreabilidade direta para pelo menos uma das 12 plataformas inspecionadas.
3. **100% Idempotente e Não-Destrutivo:** Uso estrito de `ALTER TYPE ... ADD VALUE IF NOT EXISTS`, `CREATE TABLE IF NOT EXISTS`, `ADD COLUMN IF NOT EXISTS`, `CREATE INDEX IF NOT EXISTS`, `CREATE OR REPLACE VIEW` e `INSERT ... ON CONFLICT DO NOTHING`.
